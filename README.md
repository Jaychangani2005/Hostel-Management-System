# Hostel Management System

A web-based **Hostel Management System** built with **PHP, CSS, JavaScript, and MySQL** designed to help administrators manage student hostel data, room details, facilities, fees, and occupancy statuses easily. :contentReference[oaicite:1]{index=1}

## 📌 Features

- 🔐 **Admin Authentication**  
  Secure administrators can log in to manage hostel data. :contentReference[oaicite:2]{index=2}

- 📋 **Student & Room Management**  
  Add, edit, and view student details, room occupancy, facilities, and fees. :contentReference[oaicite:3]{index=3}

- 🛏️ **Room Details Pages**  
  Showcase available rooms (Standard, Deluxe, Super Deluxe). :contentReference[oaicite:4]{index=4}

- 🔁 **Profile & Password Management**  
  Admin can update profile and reset or recover passwords. :contentReference[oaicite:5]{index=5}

- 📁 **Setup Guide Included**
